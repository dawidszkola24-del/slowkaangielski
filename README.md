# SŁÓWKAAngielski

Statyczny prototyp strony edukacyjnej.

## Publikacja przez GitHub Pages
1. Wgraj `index.html` do głównego katalogu repozytorium.
2. Otwórz Settings → Pages.
3. W sekcji Build and deployment wybierz Deploy from a branch.
4. Wybierz `main` i `/ (root)`, kliknij Save.
5. Po chwili strona będzie dostępna pod adresem GitHub Pages.

## Ważne ograniczenie
To tylko prototyp front-end. Dane są zapisywane w localStorage tej samej przeglądarki. Nie ma bezpiecznego logowania, ról, synchronizacji między urządzeniami ani wspólnej bazy. Przed użyciem z prawdziwymi uczniami należy podłączyć backend (np. Supabase), skonfigurować Auth i RLS po stronie serwera. Nie umieszczaj haseł ani kluczy serwisowych w tym pliku.
